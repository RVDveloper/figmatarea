## Descripción del Proyecto

El proyecto **"Firma Retro Waka News"** ha sido desarrollado como parte de la actividad AC6 del módulo M09. Se trata de una plataforma web diseñada con un enfoque Videojuegos retro, que combina elementos visuales nostálgicos con funcionalidades modernas, como el consumo de APIs y el uso de tecnologías avanzadas de diseño y desarrollo web.

---

## Tecnologías Utilizadas

### Lenguajes y Herramientas
- **HTML**: Estructura del proyecto.  
- **CSS**: Estilización base del diseño retro.  
- **SASS/SCSS**: Extensión de CSS para estilos más eficientes y organizados.  
- **JavaScript**: Funcionalidades dinámicas y consumo de API.  

### APIs
- **Retro GG API**: Consumo de datos proporcionados por la API de Retro GG.  
  [https://retro.gg/api/](https://retro.gg/api/)

---

## Funcionalidades Clave

1. **Diseño Retro**: Basado en una estética clásica inspirada en los videojuegos y medios retro.  
2. **Interactividad**: Implementación de botones, formularios y efectos dinámicos.  
3. **Consumo de API**: Integración con Retro GG API para obtener y mostrar contenido relevante.  
4. **Optimización con SASS**: Uso de SASS/SCSS para mejorar la organización.
